# Huro - Quickstarter

This folder is a copy of the `/src` folder of the Huro template. It is used to quickly start a new project with Huro.

It contains only few pages and components to get you started.

You can start using it by running:

```bash
pnpm dev:quickstart
```

> This set the SRC_DIR environment variable to `.quickstarter` and run the `dev` gulp script.
